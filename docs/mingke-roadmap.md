# 明课后续路线图

这份文档记下老师真正拿去上课之前还要补的事。现在先不改，后期按这个顺序做。

现在已经能用的部分：机构登录，课件和余额按机构分开；生成前看到预计费用，成功后从机构钱包扣；老师发布班级码，学生凭码上课；平台自己持有模型密钥，老师不用选供应商。

## 下一阶段：让老师能备课、能上课

按下面的顺序做。前一件做完，后一件才有用。

### 1. 机构自己管人和管钱

学校试用时，管理员能邀请其他老师，也能自己充值。学生继续凭班级码上课。

现在测试机构只有一个共用账号，加额度要改数据库。

做完的样子：

- 机构管理员能邀请老师加入本校。
- 管理员能给本校钱包充值，余额马上能用于生成。
- 老师能生成和发布，不能改账单。
- 学生不能生成，也不能看到充值入口。

### 2. 生成过程让人等得明白

点「进入课堂」之后，先看到正在写大纲，再看到写到第几页、配图和旁白做到哪了。老师可以离开页面，回来还能接着看。

做完的样子：

- 生成页始终写明当前步骤，不再长时间空白。
- 关掉页面再打开，能回到这一课的进度。
- 同一节课不会因为重复点击再扣一次费用。

### 3. 发布前能改这一课

老师听完可以改一句讲解、换一张图、改一道题，改完再发布班级码。

做完的样子：

- 讲解、配图、练习都能在发布前修改。
- 改完可以再听一遍。
- 不满意时不用整节课推倒重来。

### 4. 把上课结果收回来

班级码现在只能把学生放进课堂。老师还要知道谁来了、练习做对了多少。

做完的样子：

- 一节已发布的课能看到来上课的学生。
- 练习有对错和完成情况，老师能看汇总。
- 学生仍然只能上课，不能改课。

### 5. 同一所学校里的课可以再用

做好的课按年级、科目留下来。下个班可以再开，别的老师也可以拿去改。

做完的样子：

- 本校课程按年级和科目能找到。
- 老师可以基于一节已有的课再开一班，或复制后修改。
- 课只在本校内复用，别的机构看不到。

## 再往后：发给更多学校之前

上面五件做完，再考虑发给更多学校。那时再做：

- 内容安全：生成和上课内容要有审核，避免不适合中小学的内容直接进课堂。
- 机构开票：学校付费后能拿到发票。

这两件不放进当前这一轮给老师试用的范围。
